# tasteq listening study

A public listening study for [tasteq](https://github.com/Rafawaldrigues/tasteq),
an open-source equalizer that learns a listener's taste from loudness-matched
A/B choices. Songs are from the Free Music Archive under the licenses listed on
the site's credits page.

This Space is built by `python -m web.deploy_space` from the tasteq repository;
edit the code there, not here.
